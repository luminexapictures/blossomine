# Blossomine Website

## Publish with GitHub Pages
1. Create a GitHub repository named `blossomine`.
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Your website will be published at `https://YOUR-USERNAME.github.io/blossomine/`.

Keep the `assets` folder alongside `index.html`; the page uses relative image paths.
